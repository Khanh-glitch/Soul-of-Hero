# Local candidate asset library

`downloaded/` is generated by `tools/import_downloaded_asset_library.ps1` from
the archive hashes and deterministic source-directory fingerprints declared in
`data/asset_library/download_catalog.json`.

The directory is intentionally ignored by Git, but it is **not** hidden from
Godot. Supported images, audio and fonts are therefore available in the editor
and through `res://assets/library/downloaded/...` while remaining outside a
release commit by default.

Being present here means only **locally imported candidate**. It does not mean:

- approved for commercial redistribution;
- visually compatible with the top-down game;
- wired to a Hero, enemy, boss, VFX catalog or map;
- safe to copy into a release build.

To promote an item, copy only the selected runtime files into the canonical
namespace (`assets/characters`, `assets/vfx`, `assets/environment`, `assets/ui`
or `assets/audio`), add source/license notes, and run the relevant tests.

The importer deliberately drops archive caches, executables, scripts, nested
engine projects and macOS metadata by default. It keeps usable media plus
design/source files and license/readme material. A reviewed package can opt in
specific native resource extensions through `include_extensions` in the
catalog (for example, a self-contained Godot VFX pack). The original archives
or source directories remain the source of truth in Downloads and are verified
by SHA-256 before each import.
