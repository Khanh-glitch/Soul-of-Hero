## RPG Essentials SFX - Free

- Creator: Leohpaz
- Source: https://leohpaz.itch.io/rpg-essentials-sfx-free
- Archive: `RPG_Essentials_Free.zip`
- Archive SHA-256: `68CCA9EA2ABF49E100AC3081C7068EEF88C02662FB44D2F77296B1966316D234`
- Download/license review date: 2026-07-15
- Project use: selected and renamed WAV cues under `sfx/rpg_essentials/`

The source page permits use in personal and commercial projects and permits
editing the sounds. The original pack must not be resold or redistributed as a
standalone asset pack. Credit is optional on the source page; this project
credits Leohpaz anyway. The downloaded ZIP did not contain a separate license
file, so keep a dated copy or screenshot of the source page with release
records.

Only cues useful to the current top-down game were copied. Unused platforming,
swimming, elemental, and status sounds remain outside the project. The original
ZIP is not stored in the project.
