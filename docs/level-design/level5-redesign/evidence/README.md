# Evidence — how these files are produced

Nothing in this directory is generated by hand. The pipeline is:

| Step | Source | Output |
| --- | --- | --- |
| authoring | `tools/level5/author.py` | `data/levels/chapter_1_level_5.json` |
| offline contract | the same file, `--validate` | `logs/validate.txt` |
| reproducibility | the same file, `--check` | `logs/check.txt` |
| native frames | `tools/captures/level5_blood_crucible_capture.tscn` under Xvfb + Mesa software GL at 1280x720 | `../after/`, `../before/` |
| pairs, crops, sheet, route traces | `tools/level5/evidence.py` (Pillow) | `../comparisons/`, `crops/`, `route_trace_*.png` |
| acceptance suites | `tests/chapter_1_*`, `tests/level_5_*` | `logs/*.txt` |
| pin | `sha256sum` of the map, `git rev-parse HEAD`, `godot --version` | `source_sha256.txt` |

Two kinds of file live here and they are never mixed:

* **Native** — produced by Godot from the shipped scene at this commit. The six
  `../after/*.png` and `../before/*.png` frames, the pairs and the 4x crops
  (crops are crops of native frames, scaled nearest-neighbour, nothing drawn on).
* **Plan** — produced by Pillow from the map JSON: `route_trace_after.png`,
  `route_trace_before.png`. Both carry a banner saying they are plan diagrams.

A plan render must never be cited as a gameplay capture, and no frame here may be
reused after `data/levels/chapter_1_level_5.json` changes: `source_sha256.txt`
is the pin that makes reuse detectable.
