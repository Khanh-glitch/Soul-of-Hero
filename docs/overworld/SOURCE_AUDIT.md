# Overworld source and license audit

Written by `python3 tools/overworld/source_audit.py` from
`data/overworld/art_manifest.json` and the bytes on disk, not from memory.

## Verdict

**Every pixel in the overworld ships with a known origin.** No third-party
art is used in the overworld: the atlases are generated by this
repository's own Python painters, and the only bespoke frames are two
landmark overrides drawn here as well. Nothing is copied from an external
asset pack, so there is nothing to attribute and no license to honour for
this part of the game.

## How this is kept true

* `tools/overworld/overrides.py` rewrites the manifest on every build, so the
  record and the bytes cannot drift apart within one run.
* The atlas checksums above are recomputed here; a mismatch is reported as a
  problem, which is how a hand-edited PNG in a commit would surface.
* `--check` exits non-zero on anything unknown, so CI can hold the line.
