## Verification and boundaries

- `web/tests/b2-perception.test.ts`: 14 focused state tests: wall-blocked and actual movement; moving roll; water, teleport, tick gap, cart snap and expired predecessor; crossing and missing predecessor; real local sensing and obstruction; legacy inert traces; ID and continuation after serialization; unseen last sight, skittish behavior, visible combat, spike damage, committed beetle tell, and elder cover. `soh.test.ts` replaces the old artificial proximity-chain expectations with identity expectations while retaining the original local-trail and rain regressions.
- Locally: `npm test` **60/60**, `npx tsc --noEmit`, `npm run build`, `node --check web/e2e/salt-chain.mjs`, `node --check web/e2e/map-poi.mjs`, and `git diff --check` passed. Includes existing B1 custody/storage and Salt/Map state tests. No long browser journey was run. Local state tests are not a claim of player acceptance or exact-SHA CI.
- `Creature.knows` remains the only AI knowledge state; mark continuity lives in the existing run snapshot, not a parallel system. No home/POI GPS, autonomous browser campaign, chronology change, spawn definition, economy, geography, ARCANA or PixelFX change is introduced.
- Existing active-radius scheduling and offline wildlife freeze remain; not a wildlife/offline simulation. Existing player sight ray treats trees as transparent, whereas footprint sensing blocks trees; collision/pathing and committed projectile effects remain their existing mechanisms. In particular already-fired homing mines continue their existing tracking behavior: this does not start a new creature telegraph, and is not a new perception model. Terrain/weather sampling and LOS remain discrete approximations.
- B1 save/Continue paths are unchanged; old v3 fixture and added identity-free traces load in state tests. Client-first checksums, time and storage are not anti-tamper, trusted clock, or cross-tab synchronization. Existing npm dependency audit reports six vulnerabilities (1 low, 1 moderate, 2 high, 2 critical); no dependency changes were made.
