# Gallery — all ten locations

One page, ten rooms. Every thumbnail is a native Godot 4.7 frame at 1280×720 from
the published evidence; nothing here is re-rendered, re-used after a map edit, or
produced by the authoring preview. Levels 1–4 and 5 keep the evidence they already
had; levels 6–10 point at the frames from this pass.
