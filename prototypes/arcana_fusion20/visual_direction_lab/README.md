# ARCANA R31 Visual Direction Lab

Offline review of existing real captures, plus clearly identified concept art. **Not an accepted game build or visual approval.**

Extract the complete ZIP and open `index.html` in a modern browser. The layout is designed for a 1280×720 browser viewport with no page scrolling; use the browser's full-screen mode if browser chrome reduces the viewport. Everything needed is in `assets/`; no network or local web server is required. Pick a skill, lighting, and the two variant dropdowns; Play/Replay or drag the scrubber. Videos are independent moving-camera casts; their percentage positions are not matched ticks. The six beat buttons jump to recorded sequence checkpoints, not exact semantic event times. Their labels show last-observed source tick on the referenced source PNG (which can lag its displayed state). Source metadata JSON is bundled. Video is a lossy MP4 proxy at original 1280×720 resolution, not measured GPU FPS; use **native 1×** for unscaled original video pixels. Source PNGs, where bundled, are unchanged 1× crops, not replacement gameplay.

Choose **Directions** for 04/13/19 and **D19 layers** for matched source, A, B, A-restored and no-FX tick 489/516 crops. Diagnostic isolation images are from an older R29 pass and have a black test field; they are not gameplay. The original D and A/B/C reference HTML is bundled. Original source archive SHA-256 identifiers appear in the comparison sidebar. The AI illustrations alter the underlying background, add or change actors, and are not at proven 1× scale. They are ideas only, explicitly not gameplay evidence. The 04/13 scale sketches are hand-drawn over a frame extracted from R30 run 41444527534 at `702e365bb686595b2b33487d866218e256b23a3e`, not native spell renders. D19 concept images are non-native spatial composites using captured A/B/terrain, not supported render operations. All nine executions remain rejected; no concept bypasses source authority.

No new R31 native candidate was built. Three proposed directions per priority role and their six stages/critique are in the app. **ART_DIRECTION_REVIEW_REQUIRED:** a visual designer/creator should choose or revise the scale/shape before another implementation, especially because these early illustrations are too large or graphic and D19 compositing still fails role continuity.

Build reproducibly from a complete repository checkout: `python3 tools/arcana20_join/build_r31_lab.py /absolute/output/path` (Python standard library only). `SHA256SUMS` verifies every bundled asset; the builder prints the outer ZIP SHA-256. Stored source evidence, accepted S/F, #05 A/B and the historical all-20 provisional are not modified. No Gold, production HDR/depth, authentic combat receipt, Windows visual validation, or 60 FPS claim.
