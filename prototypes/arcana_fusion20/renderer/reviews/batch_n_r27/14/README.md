# #14 Spore Nebula — redesign in progress

Creator rejected all three random-looking directions. The brief asks for causal seed → colonies → hyphal links → traveling signals → sporulation and biological dispersal, not trees or a geometric lattice. Actual status and on-body effects are CT/R4-owned; this is visual preview only.

Baseline `d04d14d`: [41407718160](https://github.com/Khanh-glitch/Soul-of-Hero/actions/runs/41407718160) passed real-route natural normal/dim, build and Windows headless. `normal`/`dim` pair and metadata here retain that capture. All observed 1× central crops and full-viewport 35/45 in both lights were inspected. Growth and small airborne spores are visible, but clusters read as identical long purple platforms with multiple legs, joined by thick turquoise lightning-like cables; the network still feels mechanical. Not accepted art.

The follow-up separates and staggers differently sized fungal caps, narrows the hyphal cords to organic threads, retains traveling signal and spore release, and removes the generic global radial ring. This is authored redesign presentation, not a source-exact elected candidate. It requires new natural captures and source/lifecycle validation before judging improvement.
