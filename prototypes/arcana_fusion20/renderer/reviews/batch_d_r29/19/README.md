# R29 D19 isolated-layer experiment — rejected, not a creator candidate

Source and capture SHA `702a7b346c6bdee9f40d92259e726094eb7e8f57`, [run 41427686674](https://github.com/Khanh-glitch/Soul-of-Hero/actions/runs/41427686674), Godot 4.7 Linux software GL. Each paired image is the same frozen real overworld, camera, source state and tick. `bounded` is R28 and `layered` is an experimental local LDR layer reconstruction. This is not the original WebGL HDR/bloom pipeline. The isolated `star_only` and `body_only` views are diagnostic render modes that paint black inside the affected source rectangle; they are NOT natural world composites. The 14 nodes, filament and star calls remain in the source. Tick 489 and 516, normal and dim. Full uncropped isolation evidence is in the run artifacts; native-size crops here.

The original central STAR raster itself is a largely solid, rotated quadrilateral, separately visible in `star_only`. Independent pre-destination-clamp inputs peak at 0.95 (star) and 6.60/6.63 (body); 3426/3545 source pixels have all three RGBA8 channels saturated at 489/516. This independently supports overlapping additive saturation as a contributor, not a proof that it is the only cause. World warp, normal/dim brightness, source normalization and absent original post also matter. Source fragment transfer may itself already be clamped; the decomposed buffers are not original HDR output.

**Visual result:** the layered reconstruction partially reveals diagonal structure through the center, but the center still reads as a pale solid patch; coarse authored bands remain. It is not a convincing artistic repair. Rejected as the default at `0d5c9456`; the switch remains diagnostic only. Since the subsequent optimization, set `ARCANA20_D19_LAYERS=1` before the cast to collect and transport the diagnostic layers; it is off in ordinary rendering. Source-field test [41427686754](https://github.com/Khanh-glitch/Soul-of-Hero/actions/runs/41427686754) compares tracking on/off at 8.15s and passes; it is not exhaustive source parity or visual acceptance. Restore comparison was pixel-identical. No device GPU FPS, production HDR/depth or Gold claim.
