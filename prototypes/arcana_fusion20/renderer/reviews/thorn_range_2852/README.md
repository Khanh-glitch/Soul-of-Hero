# C15 Thorn Opera — moving-caster range inspection

Real-route Linux software-rendered capture: [run 41341519966](https://github.com/Khanh-glitch/Soul-of-Hero/actions/runs/41341519966), AVFX `2852addb`. This is **not** a combat, HDR, Gold, or creator-approval receipt. The 0.32 camera zoom is deliberately wider than the ordinary game camera. Targets are explicit ground positions, not fabricated enemy contacts. Both sheets contain eight unscaled 1280×720 viewport cells at bloom, with adjacent caption bars; the four individual 1280×720 files are cropped from those already JPEG-compressed sheets and re-encoded, not raw PNGs. The workflow artifacts also contain individual JPEGs and metadata: [normal](https://github.com/Khanh-glitch/Soul-of-Hero/actions/runs/41341519966/artifacts/13098135148), [dim](https://github.com/Khanh-glitch/Soul-of-Hero/actions/runs/41341519966/artifacts/13097590908). Run-local matrix PNGs were not uploaded in this run; do not claim they are retained.

At 35 and 900 world units, four bearings, three sampled observed ticks and both light modes (48 frames): no sampled simulated strand vertex was outside the union of the original raster and active added tiles; the 12-extra-tile cap was not reached (maximum 8 normal / 9 dim). This is a point-coverage measurement, **not** proof every petal, rasterized stroke, edge, or animation frame is visible. `vertices_outside`, edge counts and margins in JSON refer to the **original** 384×216 source tile, not the expanded union. Tick is last observed and can lag the presented frame.

The earlier [pre-extension run 41340710581](https://github.com/Khanh-glitch/Soul-of-Hero/actions/runs/41340710581) measured all 120 strand vertices outside the original tile in the 35-unit, right/up movement cases. Sparse non-overlapping world-only tiles now recover those moving source fields, with original scale, seeds, simulation and timing unchanged. This extends output when the real-world mount shifts/moves; it must not be described as proof the original standalone source had no intentional crop. Tile capacity is bounded, and frame seams/performance need broader real-motion review.

**Remaining independent defect:** in the 35-unit/right movement sample, the player moves far away from the fixed bloom while the original five finite-length Verlet strands follow the player. The strands and bloom visibly separate. The raster extension reveals the strands; it does not make the original finite strand geometry span arbitrary actor motion. Resolving that without changing source geometry requires an owner/cast-motion policy; stretching/replacing the original strands would be a separately labeled reinterpretation. This is not a completed seven-skill visual acceptance.
