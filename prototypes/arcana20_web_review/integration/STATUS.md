# ARCANA20 web integration — WORK IN PROGRESS, NOT PLAYTEST READY

The isolated reference-game derivative now has **experimental combat prototypes** for 20 Core items, but the requested complete build does not yet exist. **Do not publish a play-now link**: only ten source-derived effects have experimental developer-only paths, without P0 fidelity validation; the other attacks currently have no visible skill effect or telegraph. They are unsuitable for playtesting. New isolated diagnostic runs start with all 20 items, with #17–#20 in hotbar slots 4–7; an internal fixture menu can add more. Existing saves are not automatically changed, and there is no production distribution path. Twenty hand-pixelled skill-motif Core icons replace the numbered placeholders, but are provisional and not creator-approved final art. No quality modes, validated world compositing, P0 parity or target-device performance results exist. This is not production SOH or approved game balance.
