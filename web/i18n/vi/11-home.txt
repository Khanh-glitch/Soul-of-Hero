# how to play
The 14 days => 14 ngày
Keyboard and mouse => Bàn phím và chuột
Touch screen => Màn hình cảm ứng
About this game => Về game này
A run lasts 14 real days. The island keeps living while the game is closed. => Một ván kéo dài 14 ngày thật. Hòn đảo vẫn sống tiếp khi bạn tắt game.
Gather wood and stone, build a shelter, craft better gear, explore. The handbook in the game (J) teaches each part, in any order. => Kiếm gỗ và đá, dựng chỗ trú, chế đồ tốt hơn, đi khám phá. Sổ tay trong game (phím J) dạy từng phần, theo thứ tự nào cũng được.
The last 72 hours are Ragnarok: sealed vaults open and the Elders stir. => 72 giờ cuối là Ragnarok: các hầm niêm phong mở ra và các Elder thức dậy.
When the run ends, everything on the island is wiped: gear, home, recipes and the cash you carry. => Khi ván kết thúc, mọi thứ trên đảo bị xóa: đồ, nhà, công thức và số tiền bạn đang mang.
Only Ragnarok cash deposited in an Escrow Chest stays in your profile for later runs. => Chỉ Ragnarok Cash đã gửi vào Escrow Chest mới ở lại hồ sơ cho các ván sau.
If you fall, what you carry stays in a bag there. You wake at your bed or on a safe shore, and the run goes on. => Nếu bạn gục, đồ đang mang nằm lại trong một cái túi tại đó. Bạn tỉnh dậy ở giường hoặc trên một bờ biển an toàn, và ván vẫn tiếp tục.
Mouse => Chuột
Left button => Chuột trái
walk => đi
aim => ngắm
strike, or use what is in hand => đánh, hoặc dùng món đang cầm
dodge roll => lăn né
use what is in front of you => dùng thứ ở trước mặt
pick a quick slot => chọn ô nhanh
craft => chế tạo
build => xây
map => bản đồ
journey and handbook => hành trình và sổ tay
notes => ghi chú
skills => kỹ năng
menu, save and quit => menu, lưu và thoát
Drag on the left half of the screen to walk. => Kéo ở nửa trái màn hình để đi.
Tap the world to aim and strike there. => Chạm vào thế giới để ngắm và đánh vào chỗ đó.
Bottom right: Hit, Use, Roll. => Góc dưới bên phải: Đánh, Dùng, Lăn.
Under the status plate: Pack, Map, Build. => Dưới bảng chỉ số: Túi, Bản đồ, Xây.
Fonts: VT323 by Peter Hull, Pixelify Sans by Stefie Justprince, Noto Sans Symbols by the Noto Project Authors (SIL Open Font License 1.1). => Phông chữ: VT323 của Peter Hull, Pixelify Sans của Stefie Justprince, Noto Sans Symbols của The Noto Project Authors (giấy phép SIL Open Font License 1.1).
Every picture and every sound is made by the code of the game itself. No outside art or sound files are used. => Mọi hình ảnh và âm thanh đều do chính mã của game tạo ra. Game không dùng tệp hình hay tệp âm thanh nào từ bên ngoài.

# abandon from the title
Secured cash, achievements and the run history stay in your profile. The run is listed there as abandoned. => Tiền đã cất, thành tựu và lịch sử các ván vẫn ở trong hồ sơ. Ván này được ghi ở đó là đã bỏ.
The time you were away is worked out first, as for Continue; then the run ends. => Game tính phần thời gian bạn vắng mặt trước, giống như khi Chơi tiếp; sau đó ván mới kết thúc.
