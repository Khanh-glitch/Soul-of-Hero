# SOH VFX test build

Build: `cd web && VITE_FX_TEST=1 npm run build && mkdir -p releases && cp dist/index.html releases/SOH-VFX-TEST.html`. Open that HTML directly in a browser; internet is not required. This generated HTML is tracked on the review branch so the user has a durable direct download. It is a test build, not a production release.

Choose New run → Begin the 14 days. The test run has 10 physical instances of each of seven Creator Cores and four legacy Cores in its scrollable inventory, Creator Cores initially loaded with 40 Basic / 12 Refined / 4 Signature charges, legacy Cores at their normal full charge. Keys 1–7 select one of each; LMB, hold/release Q, and hold/release E use abilities. Spirit E requires selecting discovered legal ground on M map first. The QA build uses a separate IndexedDB and localStorage name, so it does not overwrite the normal game's save. This loadout is a testing fixture, not normal progression.

Owner source: `arena/3337c864-soul-of-hero` at `c0577f429c8317a15d57b330ce79384dfa801b84`; upstream PixelFX MIT `a84159688af3ca37a4be05a0d422b94451b2e24e`. Selected owner PNG combined/light atlases are byte-identical originals; hash checks against the owner manifest/pinned Foundry produced 22/22 matching page references. Existing pilot assets and gameplay were not replaced with the owner's older runtime. New visual adapters use the existing compositor: Spirit beam, teleport and hit, Dragon fire breath/tornado, Elsa snow and projectile, lightning strike, and Nature roots. There are 10 newly bundled owner effects plus the existing 11-effect pilot; this is **not** a complete 244-effect or all 21-action integration. Some imported sheets, including ice-shatter, are not yet mapped. Not all effects have full motion, enemy/day/night/obstacle visual review. Automated standalone browser check: `CHROMIUM_PATH=/path/to/chromium node e2e/vfx-test-build.mjs`.
