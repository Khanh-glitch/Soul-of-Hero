# Phạm vi và cách chạy lại (cwd: web ở SHA nguồn trong manifest)

- `npx tsc --noEmit -p .` và `npx tsc --noEmit -p tsconfig.test.json`: exit 0/0 trong typescript.txt. `npm run build`: build.txt.
- `node scripts/regression-shards.mjs <dir>`: manifest đầy đủ 225 file + SHA256 của src/tests. Hai log shard là **snapshot chưa hết**. Không cộng `passedAssertionsSeen` thành tổng PASS. Hãy thu `summary.json` khi xong, sau đó chạy từng file mất kết quả bằng runner một worker trên checkout có cùng fingerprint. Các log/partial JSON chi tiết lần chạy gốc ở `tmp/verification/full-eb04deb/` trong workspace. Không chạy baseline cùng lúc trên host ~4GiB.
- `regression-review.json`: danh sách theo file toàn inventory; phần `failures` khớp full assertion/file trên hai báo cáo chọn lọc. `paired-regression.json` ứng viên, `paired-baseline.json` parent 79ac5f0. Cùng `vitest run --maxWorkers=1 --testTimeout=120000 tests/control-tower-audit-regressions.test.tsx tests/control-tower-journey-durability.test.tsx tests/g1a-industrial-salvage.test.ts tests/cal01-world-calendar.test.ts -t 'B7:|tool matrix:|RED-[1-4]:|a cold frame costs|offline winter:|water: an exposed plot|Garden Tender keeps' --reporter=json`. 52 ngoài selector không tính vào kết quả toàn suite. Bảy lỗi inherited không được xóa hoặc miễn.
- `integration.txt`: 44/45 dưới tải, fail `npc-forage-cross-window` timeout 180s. `serial.txt`: 5/5 qua khi chạy `vitest run --maxWorkers=1 --testTimeout=120000 tests/npc-dual-rescue-same-run.test.ts tests/npc-forage-cross-window.test.ts tests/npc-world-budget.test.ts tests/mec01-f3-evac-reset.test.ts --reporter=verbose`; forage 20.334s. Phân loại lần thất bại **ENV-TIMEOUT** có phép kiểm lặp cùng test/SHA, không bỏ dòng fail gốc. `social.txt`: 4 file, 43/43. Không cộng những phép đo chồng nhau thành một full suite.
- `node <package>/capture-ledger.mjs` và `capture-census.mjs`: thêm quan sát vào bản sao tạm của test chính thức, K8 chạy **sau** assertion cuối; xóa file tạm. `node scripts/npc-native-review.mjs <production-url> <package>/native` và `node scripts/npc-browser-continuation.mjs <url> <package>/field`: input thường. Xem browser.txt/field.txt và metadata cạnh ảnh.
